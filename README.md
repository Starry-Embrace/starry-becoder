# Starry Becoder

Becoder 美化 + 可视化背景图设置用户脚本。

## 功能
- 玻璃拟态 UI（首页 / 个人主页 / 讨论 / 页）
- 自定义背景图（URL 直链），支持恢复默认
- 菜单栏注入"STARRY BECODER 设置"入口
- 兼容新旧版首页

## 安装
1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击安装：[starry-luogu.user.js](https://raw.githubusercontent.com/Starry-Embrace/starry-becoder/main/starry-luogu.user.js)

## 使用
打开洛谷任意页面 → 左侧菜单底部 "STARRY 洛谷设置" → 填写背景图 URL → 保存。
